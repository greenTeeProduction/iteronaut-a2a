# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Iteronaut A2A seriously. If you believe you've found a security vulnerability, please follow these steps:

1. **Do not disclose the vulnerability publicly**
2. **Email us** at security@example.com with details about the vulnerability
3. Include the following information:
   - Type of vulnerability
   - Full path to source files related to the vulnerability
   - Steps to reproduce
   - Potential impact

## Security Measures

- All commits must be GPG-signed
- Trivy security scanning is enabled in CI pipeline
- Dependencies are regularly updated and monitored
- Branch protection rules enforce code review

## Security Updates

Security updates will be released as soon as possible after a vulnerability is confirmed. Updates will be announced through:

1. GitHub releases
2. Security advisories on the repository
3. Communications to known affected users

Thank you for helping keep Iteronaut A2A secure.
